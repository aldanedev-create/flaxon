# Northstar Academy school portal — ORM edition

The same school website as [`../school_portal`](../school_portal), rebuilt on
Flaxon's ORM (`flaxon.db`, Tortoise 1.1.7). The pages, templates and CMS content
types are identical; only the way records are stored and exposed to Admin changed.

| | `school_portal` (legacy) | `school_portal_orm` (this one) |
|---|---|---|
| Models | plain classes + 5 hand-written `*_instance` hooks | `flaxon.db.Model` subclasses |
| Storage | `data/school.json`, rewritten wholesale | `data/school.sqlite3` (or any `DATABASE_URL`) |
| Admin hooks | you write them, or Save silently does nothing | generated by `model_adapter()` |
| Validation | none — whatever is in the dict gets stored | field types, `max_length`, `unique` |
| Listing/search/sort | in-memory scan of the JSON | SQL, database-side pagination |
| Migrations | none | `makemigrations` + `migrate` |
| Admin/CMS metadata | `data/admin.sqlite3` | same ORM database (`ADMIN_STORE_BACKEND = "orm"`) |
| Permissions | legacy defaults | `strict_permissions` + `session_bound_csrf` |

## Run it

From this directory (the project root is the directory containing `settings.py`):

```bash
python -m pip install -e ".[standard,admin]"     # from the repository root, once
python management.py check                       # settings, models, Admin registrations
python management.py makemigrations              # writes migrations/ and admin_migrations/
python management.py migrate
python management.py setup-admin --username admin
python seed.py                                   # demo courses, staff, students, CMS content
python management.py runserver --port 8010
```

| URL | Purpose |
|---|---|
| `http://127.0.0.1:8010/` | Public homepage |
| `http://127.0.0.1:8010/academics/courses` | Course directory read from the ORM |
| `http://127.0.0.1:8010/api/courses` | Public JSON read API |
| `http://127.0.0.1:8010/calendar`, `/news` | CMS-backed content |
| `http://127.0.0.1:8010/admin/login` | Admin sign-in |
| `http://127.0.0.1:8010/admin/student` | Student list (`/admin/course`, `/admin/staff`) |
| `http://127.0.0.1:8010/admin/cms/` | CMS workspace |
| `http://127.0.0.1:8010/admin/school-overview` | Custom Admin page counting ORM rows |

Development login: `admin` / `School123!` (whatever you typed at `setup-admin`).

## What changed, file by file

| File | Role |
|---|---|
| `settings.py` | `DATABASE_URL`, `ADMIN_STORE_BACKEND = "orm"`, `CMS_ENABLED` |
| `models.py` | `Student`, `Course`, `Staff` as `flaxon.db.Model` with explicit `Meta.table` |
| `admin.py` | `register(admin)` — picked up by `configure_admin(app)`; no CRUD hooks |
| `app.py` | `Flaxon.from_settings()` → `configure_admin(app)` → mount modules |
| `management.py` | Entry point for `check` / `makemigrations` / `migrate` / `setup-admin` |
| `modules/*.py` | Pages query the ORM directly instead of a repository object |
| `seed.py` | One-shot demo data, safe to re-run |
| `smoke_test.py` | End-to-end check against a running server |

The JSON repository is gone. `modules/academics.py` now does:

```python
@academics.get("/api/courses")
async def courses_api():
    courses = await Course.all().order_by("code")
    return {"courses": [course_payload(course) for course in courses]}
```

## Things worth knowing

- **`ADMIN_STORE_BACKEND = "orm"` must be set before `makemigrations`.** It adds
  the `flaxon_admin` label and generates `admin_migrations/`, so staff accounts,
  sessions, CMS content and the audit trail live in `DATABASE_URL` next to your
  tables. Commit those migrations. Changing the setting later does not move
  existing records; use `migrate-admin-store` for that.
- **Save now really writes.** A Tortoise model is wrapped by `model_adapter()`, so
  Admin gets `create_instance`/`update_instance`/`delete_instance` for free. A
  plain class does not — before the fix in `admin/views.py` that failure was
  silent (302 back to the list, nothing stored, plus a bogus `created` audit
  entry). If you register a non-ORM model you must supply the hooks yourself.
- **Edit forms carry a `_version` fingerprint.** The ORM writes conditionally, so
  a POST without it is rejected with 400. Submit every hidden field the form
  rendered — `smoke_test.py` shows the pattern.
- **Register foreign keys by their column name** (`author_id`, not `author`), or
  the field is silently dropped from the writable set.
- **Queries run inside the request's ORM context.** For standalone scripts use
  `async with app.db:` — that is what `seed.py` does.
- **Management mode skips Admin/CMS.** `app.is_management` returns early so
  commands never open the AdminStore or compile templates; modules are mounted
  after `configure_admin(app)` because they declare `requires("cms")`.

## Production changes

Set a real `SECRET_KEY` (≥32 chars) and `DEBUG=False`, point `DATABASE_URL` at
PostgreSQL (`flaxon[postgres]`), run migrations as a deploy step rather than on
startup, put media on object storage, and load the Admin password from a secret
manager. `runserver` is a development command — serve with an ASGI server without
`--reload`.
